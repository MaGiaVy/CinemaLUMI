HƯỚNG DẪN BIÊN DỊCH PDF TRÊN OVERLEAF (3 BƯỚC)
==============================================

1. Truy cập https://www.overleaf.com -> New Project -> Upload Project
   -> Chọn file: BaoCao_LumiCinema_Overleaf.zip

2. Ở góc trên bên trái, nhấn "Menu" -> mục "Compiler" -> chọn "XeLaTeX"
   (Bắt buộc chọn XeLaTeX để hiển thị tiếng Việt Unicode đẹp và chuẩn).

3. Mở file main.tex, điền thông tin Trường, Khoa, GVHD, Lớp, MSSV ở đầu file
   (dòng 6 - 20) -> nhấn "Recompile" để xuất file PDF hoàn chỉnh!

Ghi chú:
- Toàn bộ 73 sơ đồ PlantUML đã được render ở độ phân giải 300 DPI (không vỡ nét).
- Khung ảnh BFD ở Chương 2 (chapters/02_bfd_va_ke_hoach.tex) đang để placeholder
  để nhóm tự chèn ảnh BFD sau nếu cần.
